# 仕様判断が必要な項目

2026-10-10 の全機能検証で見つかった、コードと README から一意に決まらない挙動の一覧。
ここにあるものは不具合として修正していない。決まったら該当行を消して実装する。

決定済み(2026-10-10 利用者回答):

- 読み始めは「押した文字から」のまま。語頭・文頭へは寄せない。
- 絵文字・装飾記号・URL は読み飛ばす(`speech.py` の `strip_unspoken` で実装済み)。
